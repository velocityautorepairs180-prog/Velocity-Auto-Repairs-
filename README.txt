VELOCITY AUTO REPAIRS/SERVICES — ANDROID PROJECT

Requirements:
- Android Studio
- Android SDK 35
- Internet connection for Gradle dependencies

Build:
1. Extract this ZIP.
2. Open the extracted folder in Android Studio.
3. Let Gradle sync.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the generated APK on your Android phone.

Application ID: com.velocityauto.app
Version: 1.0
